# KU Join

ระบบลงทะเบียนงาน/กิจกรรมด้วย PHP และ MySQL สำหรับ XAMPP

## เริ่มใช้งาน

1. เปิด Apache และ MySQL ใน XAMPP
2. นำเข้าไฟล์ `schema.sql` ผ่าน phpMyAdmin
3. เปิด `http://localhost/ku-join/`

บัญชีผู้ดูแลตัวอย่าง: `admin` / `admin123` (ควรเปลี่ยนรหัสผ่านก่อนนำขึ้นใช้งานจริง)

ผู้ดูแลจัดการชื่องาน วันที่ สถานที่ ประเภทผู้เข้าร่วม และตารางเวลาได้จาก `/admin/login.php`
